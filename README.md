## 🚀 How to Run

### Prerequisites
- ☑️ Java JDK 8 or higher → [Download](https://www.oracle.com/java/technologies/downloads/)
- ☑️ Any IDE — IntelliJ IDEA · Eclipse · VS Code · or Terminal

### Compile & Execute
```bash
# Navigate to the folder
cd Programs

# Compile
javac "Armstrong number.java"

# Run
java ArmstrongNumber
```

### UML Diagrams
> Open `.mdj` files using **[StarUML](https://staruml.io/)** — supports all diagram types included.
